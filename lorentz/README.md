# Lorentz

The rest length is 1.00 m. Moving length is the square root of (1 − β²) metres. β is the speed as a fraction of the speed of light.

The bin is 0.00 c, 0.40 c, 0.60 c, 0.80 c, and 0.90 c. The mark is 0.80 m, within 0.02 m. Only 0.60 c hits.
