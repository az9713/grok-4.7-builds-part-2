# Bridge

A Wheatstone bridge on a 2 V battery. The arms are P = 100 Ω, Q = 200 Ω, and R = 150 Ω. The unknown arm is X.

The galvanometer voltage is 2 × (R / (P + R) − X / (Q + X)). Null is X = R × Q / P = 300 Ω.

The bin is 100, 150, 220, 300, and 470 Ω. Only 300 Ω is within 0.001 V of null.
