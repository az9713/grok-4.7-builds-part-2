# Swarm Brief

Grok 4.6 piece. A Rhai swarm researches a frozen question (why steel ships rust at the waterline), keeps a locked copperplate figure language, and ships an HTML explainer.

Open `ui/index.html` for the watchable DAG (fixture run). Open `explainer/index.html` for the artifact. Workflow: `workflows/waterline.rhai`.

Numbers and labels are SVG/HTML. The hull plate is Imagine.
