# Sabine

The room volume is fixed. Reverberation time is 48 / area seconds. Area is in square metres.

The bin is 16, 24, 30, 40, and 48 m². The mark is 1.60 s, within 0.02 s. Only 30 m² hits. The other four read 3.00 s, 2.00 s, 1.20 s, and 1.00 s.

Open `play/index.html`.
