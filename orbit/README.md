# Orbit

Speed is 20 divided by the square root of the radius. Radius is in metres. Speed is in m/s.

The bin is 4, 16, 25, 64, and 100 m. The mark is 4.00 m/s, within 0.05 m/s. Only 25 m hits. The other four read 10.00 m/s, 5.00 m/s, 2.50 m/s, and 2.00 m/s.
