# Hour Angle

A courtyard dial. Declination uses Cooper's formula, 23.44° sin(360° (284 + day) / 365). Altitude and azimuth follow from the latitude and the hour angle. Shadow length is 1 / tan(altitude).

At latitude 51.5°, day 81, solar noon, altitude is 38.5°. The dial has no score.
