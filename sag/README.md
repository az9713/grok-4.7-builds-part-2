# Sag

The radius is 20 cm. The sagitta is 20 × (1 − cos(angle / 2)). The angle is in degrees.

The bin is 0, 60, 90, 120, and 180°. The mark is 10.00 cm, within 0.005 cm. Only 120° hits. The other four read 0.00 cm, 2.68 cm, 5.86 cm, and 20.00 cm.
