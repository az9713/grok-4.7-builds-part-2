# String

A string 1.20 m long is fixed at both ends. The wave speed is 240 m/s. Harmonic n has frequency n × 100 Hz. Nodes sit every 1.20 / n metres, including the two ends.

The chalk mark is 0.40 m from the left end. A node is on the mark when the distance is 0.02 m or less. From harmonics 1 to 5, only harmonic 3 does that. Its frequency is 300 Hz.
