# Pendulum

Two rods, each 1 m, and two bobs, each 1 kg. Angles are measured from the downward vertical. The step is RK4 at 1/240 second. g is 9.81 m/s².

The start is 120° and −10°, at rest. Energy at that start is 0.1490. The bench has no score.

Open `play/index.html`.
