# Buckle

Critical load is 1000 divided by length times length. Length is in centimetres. Load is in newtons.

The bin is 2, 4, 5, 8, and 10 cm. The mark is 40.0 N, within 0.2 N. Only 5 cm hits. The other four read 250.0 N, 62.5 N, 15.6 N, and 10.0 N.

Open `play/index.html`.
