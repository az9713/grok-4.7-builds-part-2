# Bernoulli

Still air is 101300 Pa. Density is 1.20 kg/m³. Throat pressure is (101300 − (3 × speed²) / 5) / 1000 kilopascals. The term (3 × speed²) / 5 is ½ × 1.20 × speed².

The bin is 20, 30, 40, 50, and 60 m/s. The mark is 99.80 kPa, within 0.05 kPa. Only 50 m/s hits.
