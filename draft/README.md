# Draft

A box hull floats in fresh water of density 1.00 g/cm³. While the hull density is below 1, the submerged fraction equals that density. Density 1.20 sinks the hull.

The bin is 0.40, 0.50, 0.60, 0.75, and 1.20. The chalk mark is 0.60 of the hull height, within 0.02. Only 0.60 hits.
