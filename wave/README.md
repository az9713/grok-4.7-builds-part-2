# Wave

The frequency is 200 Hz. Speed in metres per second is 2 × the wavelength in centimetres.

The bin is 50, 100, 170, 200, and 250 cm. The mark is 340 m/s, within 1 m/s. Only 170 cm hits. The other four read 100 m/s, 200 m/s, 400 m/s, and 500 m/s.
