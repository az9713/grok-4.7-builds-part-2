# Tau

The capacitance is fixed. Time is the resistance divided by 5. Resistance is in kilohms. Time is in seconds.

The bin is 5, 10, 15, 20, and 25 kΩ. The mark is 3.00 s, within 0.02 s. Only 15 kΩ hits. The other four read 1.00 s, 2.00 s, 4.00 s, and 5.00 s.
