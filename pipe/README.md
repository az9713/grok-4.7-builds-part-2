# Pipe

The pipe is closed at one end. Sound speed is 340 m/s. Frequency is 85000 / length hertz when length is in millimetres. That is 340 / (4 × length in metres).

The bin is 0.20 m, 0.25 m, 0.34 m, 0.50 m, and 0.85 m. The mark is 250 Hz, within 1 Hz. Only 0.34 m hits.
