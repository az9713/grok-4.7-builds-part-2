# Boost

One speed stays at 0.50 c. The sum is (0.50 + v) / (1 + 0.50 × v). v is the speed you choose, in units of c.

The bin is 0.20 c, 0.40 c, 0.50 c, 0.60 c, and 0.80 c. The mark is 0.75 c, within 0.005 c. Only 0.40 c hits. The other four read 0.64 c, 0.80 c, 0.85 c, and 0.93 c.
