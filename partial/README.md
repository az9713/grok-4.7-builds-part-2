# Four Partials

An additive tone. Four sine partials start at ratios 1, 2, 3, and 5. The fundamental starts at 220 Hz. Each slider sets a partial’s height. The amber line is their sum over one cycle.

Drag the string to write a loudness curve. The curve loops every 2 seconds while the bench sounds. The bench has no score.

Open `play/index.html`.
