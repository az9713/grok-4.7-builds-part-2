# Shunt

One resistor stays at 12 Ω. The parallel value is (R × 12) / (R + 12) ohms. R is the resistor you choose.

The bin is 4, 6, 12, 24, and 60 Ω. The mark is 6.00 Ω, within 0.005 Ω. Only 12 Ω hits. The other four read 3.00 Ω, 4.00 Ω, 8.00 Ω, and 10.00 Ω.

Open `play/index.html`.
