# Gimbal Goods

Fictional catalog for one lamp. Six `image_edit`-chained plates, two purchasable finishes, a hold ticket persisted in `localStorage`.

Built with Grok Build.

## Play

Open `gimbal-goods/play/index.html` in a browser, or:

```
python3 -m http.server 8766
```

then `http://127.0.0.1:8766/gimbal-goods/play/`.

Click a plate to promote it to the hero. Add Graphite or Brass to the hold. Quantities survive a reload.

## Art

Lock: `art/lamp.jpg`. Variants: front, top, off, desk, brass. Same armature in every photograph.
