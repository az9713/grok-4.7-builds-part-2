# Sort Case

A reduced type case for one ticket, SOCKET DARK. The stick shows mirrored, reversed metal. The proof shows the readable line. The measure is 24 units. The ticket uses 21.

Sorts are 2 units, except I, J, and L at 1, M and W at 3, and a space at 1. Lock the chase, then pull the proof.

Open `play/index.html`.
