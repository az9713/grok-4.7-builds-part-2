# Swing

One pendulum. Gravity is 9.81 m/s². The period is 2 × π × the square root of length / 9.81. Length is in metres. The period is in seconds.

The bin is 0.50, 0.75, 0.99, 1.25, and 1.60 m. The mark is 2.00 s, within 0.02 s. Only 0.99 m hits.
