# Isochore

The flask volume stays fixed. Pressure is (100 × temperature) / 300 kilopascals. The start is 100.0 kPa at 300 K.

The bin is 300, 330, 360, 390, and 450 K. The mark is 120.0 kPa, within 0.2 kPa. Only 360 K hits. The other four read 100.0 kPa, 110.0 kPa, 130.0 kPa, and 150.0 kPa.

Open `play/index.html`.
