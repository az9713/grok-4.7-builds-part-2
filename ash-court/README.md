# Ash Court

Eighteen-card microgame. Woodcut lock on the magistrate; rain plate is an `image_edit`. Rank and suit live in HTML, never in the bitmap.

Open `play/index.html`. Follow suit if you can. Highest card of the led suit wins the trick. The bench hand is face down until a card is played.

Print the rulebook from the page (`Print rulebook`).

Built with Grok Build. MIT.
