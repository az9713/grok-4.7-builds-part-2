# Slit

A single slit. The wavelength is 500 nm. The screen is 2.00 m away. The first minimum is 1 / width millimetres, with the width in millimetres. That is 2.00 m times 500 nm, divided by the slit width.

The bin is 0.25, 0.40, 0.50, 0.80, and 1.00 mm. The mark is 2.00 mm, within 0.05 mm. Only 0.50 mm hits.
