# Heddle

A four-shaft loom. Eight warp ends thread 1, 2, 3, 4, 1, 2, 3, 4. A treadle lifts the shafts tied to it. Risen warp covers the weft.

The ticket is 2/2 twill: treadle 1 lifts shafts 1 and 2, treadle 2 lifts 2 and 3, treadle 3 lifts 3 and 4, treadle 4 lifts 4 and 1. Throw that order twice.
