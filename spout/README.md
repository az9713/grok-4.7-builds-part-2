# Spout

Efflux speed is 2 times the square root of the depth. Depth is in metres. Speed is in m/s.

The bin is 1, 4, 9, 16, and 25 m. The mark is 6.00 m/s, within 0.05 m/s. Only 9 m hits. The other four read 2.00 m/s, 4.00 m/s, 8.00 m/s, and 10.00 m/s.

Open `play/index.html`.
