# Twin Orbit

Two locked heroes, one gravity-puzzle room. The pilot (WASD) and the mechanic (arrows) hand a battery across a gap.

Art is edit-chained from two canonical Imagine stills (`pilot.jpg`, `mechanic.jpg`). Magenta is the key *and* the void.

Open `play/index.html`. Pilot: WASD move, E pick up, F throw. Mechanic: arrows move, . pick up, / throw. Reach the socket.

Built with Grok Build. MIT. No secrets.
