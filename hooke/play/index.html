Rules

  1. The spring constant is 0.40 N/mm.
  2. Extension is force / 0.40 millimetres.
  3. The mark is 10.0 mm. A hit is within 0.2 mm.
  4. 4 N is the hit. The line says The spring meets the mark.
  5. 2 N reads 5.0 mm. 3 N reads 7.5 mm. 5 N reads 12.5 mm. 8 N reads 20.0 mm.
  6. Those four miss. The line says The spring misses the mark.
